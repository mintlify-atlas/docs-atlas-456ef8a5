The Smart CX support chat gives you access to a virtual assistant and your ticket history without leaving any page in the portal. A floating chat button sits in the bottom corner of every authenticated screen. Click it to open the chat window, and click it again to close it.

## Opening the chat

<Steps>
  <Step title="Locate the chat button">
    Look for the chat icon button in the bottom-right corner of any page. It is visible on all authenticated pages in the portal.
  </Step>
  <Step title="Click to open">
    Click the button to open the chat window. It opens to the **Live Chat** view by default, with a welcome message from the virtual assistant.
  </Step>
  <Step title="Type your message">
    Enter your question or request in the message input field at the bottom of the chat window, then press **Send** or hit Enter to submit.
  </Step>
  <Step title="Read the response">
    The assistant replies in the chat thread. An animated typing indicator appears while the response is loading. Continue the conversation by sending follow-up messages.
  </Step>
</Steps>

## Live Chat

When you open the chat, you are greeted with:

> "Hi there! I'm your Smart CX Virtual Assistant. How can I help you today?"

You can ask the virtual assistant about:

- **Billing questions** — charges, due dates, billing cycles, and payment history
- **Service issues** — outage status, meter readings, and service requests
- **Account information** — plan details, service addresses, and account balances
- **Portal navigation** — how to find features or complete common tasks

Each message you send includes your full conversation history, so the assistant retains context across the whole session. You do not need to repeat yourself if you ask a follow-up question.

<Note>
  Your conversation history is sent with every message so the assistant can maintain context. The more of the conversation that has occurred, the more context the assistant has — but very long sessions may approach the model's context window limit. If the assistant seems to lose track of earlier details, start a new chat session.
</Note>

### When the service is unavailable

If the chat server cannot be reached, the assistant displays:

> "I'm having trouble connecting to the support server right now. If this is an emergency, please call **1-800-SMART-CX**."

Call **1-800-SMART-CX** any time you need immediate assistance and the virtual assistant is unavailable.

## My Tickets

Switch to the **My Tickets** tab inside the chat window to see a list of your existing support tickets. Each ticket shows:

| Field | Description |
|-------|-------------|
| **Ticket ID** | Unique identifier, e.g. `TKT-8902` |
| **Subject** | Brief description of the issue, e.g. `Billing Dispute` |
| **Status** | Current state of the ticket: `In Progress`, `Closed`, or similar |
| **Opened** | The date the ticket was submitted |

Status badges make it easy to scan for tickets that are still active at a glance.

<Tip>
  Use the **My Tickets** view to check the status of any issue you have already reported. If a ticket is still marked **In Progress**, you can reference its ID when chatting with the virtual assistant for faster context.
</Tip>
